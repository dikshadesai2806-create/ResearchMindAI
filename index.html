GitHub Pages Deployment Guide

If the application doesn't load within a few seconds on GitHub Pages, verify your repository settings:

  1. Go to your GitHub repository Settings > Pages
  2. Under Source, choose GitHub Actions (automatically builds your app)
  3. Alternatively, run npm run deploy in your terminal and set Source branch to gh-pages
  4. Avoid selecting branch main with folder / (root), as browsers cannot run uncompiled TypeScript directly.
